# Automatizaciones con n8n

Workflows que diseñé y construí con **n8n**, listos para importar. Cada carpeta tiene el `workflow.json` y un README que explica qué resuelve y cómo funciona.

| Workflow | Qué hace | Integraciones |
|---|---|---|
| [Gestión de vacaciones](./gestion-vacaciones) | Solicitud, validación y aprobación de vacaciones por RR. HH. | PostgreSQL · Discord · Gmail · Google Calendar |
